# RetroPie-Internet-Radio

RetroPie setup met internet radio.

## Installatie

```bash
git clone https://github.com/itsdarklikehell/RetroPie-Internet-Radio.git
cd RetroPie-Internet-Radio
./install.sh
```

## Gebruik

Start RetroPie op en internet radio start automatisch.
